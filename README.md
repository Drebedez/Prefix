## Prefix:

Es un proyecto con el fin de ayudar a las aplicaciones de Discord a manejar eventos de "messageCreate"
de discord detectando el prefijo y ejecutando la funcion correspondiente asignada con los parametros
introducidos.
El proyecto se desarrolla en base a las necesidades de su autor en sus proyetos y no busca sustentar las necesidades que puedan surgir si terceros hacen uso de este.
